ChatWave – Connect. Chat. Share. 💬

ChatWave is a Java-based real-time chat application developed using TCP socket programming and multithreading.

🚀 Features

- Real-time group messaging
- Private messaging between users
- Online users list
- Join and leave notifications
- Message timestamps
- Typing indicators
- Message delivery and read receipts
- Logout functionality
- Interactive Java Swing GUI

🛠️ Technologies Used

- Java
- Java Swing
- TCP Socket Programming
- Multithreading
- VS Code

📁 Project Structure

- "ChatServer.java" – Starts the chat server.
- "ClientHandler.java" – Handles individual client connections and messages.
- "ChatClient.java" – Manages client-server communication.
- "ChatGUI.java" – Provides the graphical user interface.

▶️ How to Run

1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the files:

javac *.java

5. Start the server:

java ChatServer

6. Open another terminal and start a client:

java ChatGUI

7. Run multiple clients to test group and private messaging.

💌 Private Messaging

Select an online username to start a private conversation.

You can also use:

/w username message
